# DevDoc AI - Frontend README

Modern React + Vite frontend for AI README generator.

## Setup

```bash
cd frontend
npm install
```

## Development

```bash
npm run dev
```

Runs on `http://localhost:5173`

## Build

```bash
npm run build
```

## Features

- 🎨 Modern dark UI with glassmorphism
- ⚡ Real-time markdown preview
- 📝 Live README editor
- 🚀 GitHub repository analyzer
- 🤖 AI-powered content generation
- 📥 Download README.md

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- React Router
